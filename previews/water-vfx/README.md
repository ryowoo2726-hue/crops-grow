# 물방울 VFX 독립 미리보기

같은 폴더의 `index.html`을 Chrome 또는 Edge로 열면 됩니다. 서버나 설치가 필요하지 않습니다. 기존 `assets/optimized/` 파일을 상대 경로로 사용하므로 HTML만 다른 위치로 옮기면 이미지가 표시되지 않습니다.

- 물주기: 웅크리기 → 포물선 점프 → 물 튀김·물결 → 작물 반응 → 마스코트 복귀
- 미션·퀴즈: 보상 게이지 → 영양분 입자 → 뿌리 흡수 → 작물 반응
- 일시정지, 재생 속도, 장면 이동으로 각 순간을 확인합니다.
- 수치는 매 재생마다 20%부터 시작하는 시연값입니다. 물주기는 +50%, 영양분은 +30%입니다.

HTML Canvas로 동작과 타이밍을 검토하는 초기 시안입니다. 마스코트는 기존 그림 전체를 변형하며, 세부 표정·팔다리 리깅은 하지 않습니다. 실제 적용 시 Flutter 애니메이션으로 옮겨야 합니다.

`lib/`, Flutter 진입점, 운영 배포 설정은 수정하지 않았습니다. 네트워크 API, localStorage, 학생 DB를 사용하지 않습니다. 에셋 원본도 수정하지 않았습니다. 이 폴더는 현재 Flutter 빌드의 배포 대상에 포함되지 않습니다.
