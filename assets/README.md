# 게임 이미지와 디자인 자료

현재 앱 실행·검증 방법은 [프로젝트 안내](../README.md)를 참고하세요.

## 최신 최적화 (Git 업로드 승인·배포 진행 중)

- 원본 PNG·TTF·OFL은 보존합니다. 성장 44장과 밑동 기준은 그대로이며, 현재 화면에 필요한 성장 이미지부터 준비합니다.
- `py scripts/prepare-images.py`는 기존 WebP와 함께 도감 `-thumb`·정원 `-garden`용 256px 복사본을 생성합니다. 도감 11장 합계는 591,860 → 224,528바이트입니다. 수확 팝업에는 512px 이미지를 계속 사용합니다.
- 학교 배경은 해상도 768×1376을 유지하고 WebP quality 90으로 507,794 → 30,908바이트로 줄였습니다. 알파 일치·평균 RGB 오차 3/255 미만을 검사합니다. 다른 이미지는 lossless WebP이며 생성기가 픽셀 일치를 확인합니다.
- `py scripts/prepare-fonts.py`는 한글 11,172자·라틴·기호 등 14,608자(1,634,504바이트)를 초기 폰트로, 한자 등 8,566자(2,315,640바이트)를 후속 폰트로 나눕니다. 두 파일의 합집합이 원본 23,174자를 포함하고 가변 굵기 100~900을 유지하는지 검사합니다. 후속 폰트는 화면 에셋 준비 뒤 로드하며, 그 전에 필요하면 Flutter 기본 폰트 대체가 동작합니다.
- 생성기는 Dart 매핑·pubspec·HTML 선로딩 경로도 갱신합니다. 개발 PC에 Pillow·fonttools·brotli가 필요하지만 배포 서버에는 필요 없습니다. 새 에셋·매핑을 함께 관리합니다. 최신 사용자 지시로 업로드가 승인되었으며 결과는 인수인계 최상단에 기록합니다.

아래 수치는 이전 최적화 이력입니다.

- `crops/`: 작물 11종 × 성장 4단계와 수확물, 총 55장.
- `environment/`: 학교 텃밭 배경과 논·마른 흙 바닥.
- `characters/`: 물방울 캐릭터 원본.
- `fonts/`: Noto Sans KR 글꼴과 OFL 라이선스.

웹 배포에는 `fonts/NotoSansKR-fc0b385edc9df480.woff2`를 사용합니다. 원본 TTF의 전체 글리프·문자 매핑·가변 굵기를 유지한 WOFF2 압축본으로, 10,414,588바이트에서 3,908,652바이트로 줄였습니다. 원본 `NotoSansKR.ttf`와 OFL 라이선스도 보관합니다. 재생성은 `python -m fontTools.ttLib.woff2 compress assets/fonts/NotoSansKR.ttf -o assets/fonts/NotoSansKR.woff2`로 수행합니다. 이 앱의 배포 대상은 Flutter Web이며 WOFF2는 Flutter 데스크톱 실행용 폰트가 아닙니다.
- `optimized/`: 화면용 WebP 복사본. 파일 내용의 SHA-256을 파일명에 포함해 장기 캐시와 안전한 갱신을 함께 사용합니다.
- `ui-mockups/`: 원본 화면 디자인 참고 시안.
- `asset-manifest.json`: 원본 이미지 메타데이터와 컬러 토큰.

실제 앱 리소스는 `pubspec.yaml`에 등록합니다. 게임 화면은 `lib/main.dart`, 11종 공통 성장 애니메이션은 `lib/crops/crop_growth.dart`에 있습니다. 이전 HTML 미리보기·JavaScript 성장 렌더러·SVG 아이콘은 Flutter 전환 후 정리했습니다.

작물과 바닥 PNG는 1024×1024 투명 이미지이며 작물 밑동은 가로 50%, 세로 82% 위치를 기준으로 맞췄습니다. 벼는 `field-base.png`, 나머지 작물은 `field-dry-base.png`와 조합합니다.
