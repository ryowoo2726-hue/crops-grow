# 다른 노트북 서버·저장소 설정 설명서

이 설명서는 **서버를 실행할 Windows 노트북**에서 따라 합니다. 최초 설정 후에는 PowerShell 창 두 개에서 서버와 터널을 실행하면 됩니다.

- 학생 접속: https://cropgrow.sangsangbar.com
- 백엔드 주소: https://cropgrow-api.sangsangbar.com
- 소스: https://github.com/ryowoo2726-hue/crops-grow
- 이미 만든 Cloudflare Tunnel 이름: `cropgrow-api`

## 1. 폴더 세 개를 구분하기

| 예시 경로 | 용도 | 보관 방법 |
|---|---|---|
| `C:\GrowGame\crops-grow` | 다운로드한 서버 코드 | 새 버전으로 업데이트 가능 |
| `C:\GrowGameData` | 실제 학생 기록 DB | 계속 유지. 코드와 따로 보관 |
| `C:\GrowGameBackups` | 날짜별 DB 백업 | 별도 USB 등에 추가 복사 가능 |

실행 중인 DB는 노트북의 **로컬 디스크**에 둡니다. Google Drive·OneDrive·공유 폴더를 DB 위치로 선택하지 마세요. 코드 폴더를 새로 받아도 같은 DB 폴더를 선택하면 기록을 이어갑니다. GitHub에는 코드만 올리며 학생 DB를 올리지 않습니다.

DB에는 학생 PIN의 해시, 성장률, 수확 기록, 퀴즈와 정답 등이 저장됩니다. 이미지·폰트·화면은 Cloudflare가 제공합니다.

## 2. Node.js와 cloudflared 준비하기 — 최초 1회

### Node.js

1. [Node.js 공식 다운로드](https://nodejs.org/en/download/)에서 **24 LTS, 24.13 이상**의 Windows Installer를 설치합니다. 현재 코드가 요구하는 버전은 24 계열입니다.
2. 설치 후 PowerShell을 새로 열고 확인합니다.

```powershell
node --version
```

`v24.`로 시작하면 됩니다. SQLite는 Node 기본 기능으로 사용하므로 별도 DB 프로그램이나 `npm install`은 필요 없습니다. 서버 노트북에는 Flutter도 필요 없습니다.

### cloudflared

1. [Cloudflare 공식 다운로드 안내](https://developers.cloudflare.com/tunnel/downloads/)에서 노트북에 맞는 Windows 실행 파일을 받습니다. 일반적인 Intel/AMD 64비트 Windows는 amd64/x64입니다.
2. 폴더 `C:\GrowGameTools`를 만들고 실행 파일 이름을 `cloudflared.exe`로 바꿔 넣습니다. 확장자가 이중으로 붙지 않도록 파일 탐색기의 파일 확장명 표시를 켜서 확인합니다.
3. PowerShell에서 확인합니다.

```powershell
& 'C:\GrowGameTools\cloudflared.exe' --version
```

이 설명서는 수동 실행 방식입니다. Cloudflare 안내에 나오는 `service install` 명령은 실행할 필요가 없습니다.

## 3. 프로젝트 내려받기

GitHub 저장소에서 **Code → Download ZIP**으로 받고 압축을 풉니다. 폴더 이름을 정리해 다음 파일이 실제로 있는지 확인합니다.

```text
C:\GrowGame\crops-grow\backend\start.ps1
C:\GrowGame\crops-grow\backend\start-tunnel.ps1
```

Git이 설치되어 있다면 ZIP 대신 다음 명령을 사용할 수 있습니다. 대상 폴더가 비어 있을 때 처음 한 번만 실행합니다.

```powershell
git clone https://github.com/ryowoo2726-hue/crops-grow.git C:\GrowGame\crops-grow
```

이하 명령은 프로젝트 위치가 `C:\GrowGame\crops-grow`인 경우입니다. 다르게 저장했다면 `Set-Location` 경로를 바꿉니다.

## 4. 서버 실행과 DB 저장 폴더 선택

첫 번째 PowerShell 창에서 실행합니다.

```powershell
Set-Location 'C:\GrowGame\crops-grow'
$env:FRONTEND_ORIGINS='https://cropgrow.sangsangbar.com'
.\backend\start.ps1
```

최초 실행 시 폴더 선택창이 열립니다. **`C:\GrowGameData`를 만들고 선택**합니다. 이 폴더 안에 `growgame.sqlite`가 자동 생성됩니다. `growgame.sqlite-wal`, `growgame.sqlite-shm` 파일이 함께 나타날 수도 있으며 정상입니다.

폴더 선택은 해당 Windows 사용자 계정에 저장됩니다. 다음부터는 같은 폴더를 자동으로 사용합니다. 서버가 실행 중인 첫 번째 창은 그대로 둡니다.

새 PowerShell 창에서 아래 명령으로 서버만 먼저 확인합니다.

```powershell
Invoke-RestMethod 'http://127.0.0.1:8787/api/health'
```

`ok` 값이 `True`면 노트북 내부 서버가 정상입니다. 아직 이 단계만으로 외부 학생들이 접속할 수는 없습니다.

### 스크립트 실행이 차단될 때

학교의 실행 정책을 먼저 확인합니다. 허용되는 개인 설정 범위라면 현재 PowerShell 창에만 다음 설정을 적용한 뒤 재실행합니다.

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
```

ZIP에서 받은 두 스크립트가 인터넷 다운로드 파일로 차단되었다면, 공식 저장소에서 받은 파일임을 확인한 뒤 각각 파일 속성의 **차단 해제**를 적용합니다. 학교 조직 정책으로 막힌 경우 담당자에게 실행 허용을 요청합니다.

## 5. Cloudflare 터널 연결 — 최초 토큰 입력

1. [Cloudflare 대시보드](https://dash.cloudflare.com)에 `sangsangbar.com`을 관리하는 계정으로 로그인합니다.
2. **Networking → Tunnels → cropgrow-api → Add a replica**에서 기존 터널의 토큰을 확인합니다. 화면 구성에 따라 Zero Trust의 Networks/Connectors 안에 Tunnels가 표시될 수 있습니다.
3. Windows 설치 명령 전체가 아니라 **터널 토큰 문자열만** 복사합니다. `cloudflared service install` 뒤에 붙는 긴 문자열이 토큰입니다.
4. 두 번째 PowerShell 창에서 실행합니다.

```powershell
Set-Location 'C:\GrowGame\crops-grow'
$env:Path='C:\GrowGameTools;'+$env:Path
.\backend\start-tunnel.ps1
```

처음에는 토큰 입력을 요청합니다. 붙여넣고 Enter를 누릅니다. 입력 문자가 화면에 표시되지 않는 것은 정상입니다. 토큰은 이 노트북의 현재 Windows 사용자에게 암호화해 저장하며 다음부터 다시 묻지 않습니다.

첫 번째 서버 창과 두 번째 터널 창을 모두 열어 둡니다. **같은 터널이나 DNS를 새로 만들지 않아도 됩니다.** 기존 설정은 다음과 같습니다.

| Cloudflare 설정 | 값 |
|---|---|
| Tunnel | `cropgrow-api` |
| Public hostname | `cropgrow-api.sangsangbar.com` |
| Service | `http://127.0.0.1:8787` |

터널 토큰은 관리자용 비밀 값입니다. GitHub·설명서·학생에게 전달할 자료에 넣지 않습니다. 다른 노트북이나 Windows 계정으로 바꾸면 토큰을 다시 입력해야 합니다.

## 6. 외부 접속 확인

```powershell
Invoke-RestMethod 'https://cropgrow-api.sangsangbar.com/api/health'
```

외부 주소에서도 `ok: True`가 나오고 Cloudflare Tunnel 상태가 `Healthy`이면 연결된 것입니다. 휴대전화에서 Wi-Fi를 끄고 모바일 데이터로 [게임 화면](https://cropgrow.sangsangbar.com)을 열어 입장·물주기·새로고침 후 재입장을 확인합니다.

이제 학생이 최초 입장할 때 학년·반·번호와 숫자 4자리 PIN으로 등록합니다. 관리용 로그인 화면은 따로 없습니다. 현재는 먼저 등록한 사람이 해당 번호의 PIN을 정하므로 행사 전에 번호 확인 방식도 정해 주세요.

학교 인터넷은 외부에서 노트북으로 들어오는 포트를 열 필요가 없습니다. 노트북에서 Cloudflare로 나가는 **7844 TCP/UDP** 통신이 필요합니다. UDP 연결이 안 되면 두 번째 창에서 Ctrl+C 후 다음으로 다시 실행합니다.

```powershell
.\backend\start-tunnel.ps1 -Protocol http2
```

TCP도 차단되면 학교 네트워크 담당자에게 허용을 요청합니다. [Cloudflare 공식 방화벽 조건](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/tunnel-with-firewall/)을 전달하면 됩니다.

## 7. 행사 당일 켜기와 끄기

**켜기:** 첫 번째 창에서 서버, 두 번째 창에서 터널을 실행합니다. 매번 새 PowerShell 창에서는 환경변수도 다시 지정합니다.

첫 번째 창:

```powershell
Set-Location 'C:\GrowGame\crops-grow'
$env:FRONTEND_ORIGINS='https://cropgrow.sangsangbar.com'
.\backend\start.ps1
```

두 번째 창:

```powershell
Set-Location 'C:\GrowGame\crops-grow'
$env:Path='C:\GrowGameTools;'+$env:Path
.\backend\start-tunnel.ps1
```

저장 폴더와 토큰은 기억합니다. 노트북의 전원을 연결하고 행사 중 절전 모드로 들어가지 않게 설정합니다. 서버가 꺼져도 프론트 사이트는 열리지만 로그인·기록 저장·보상 처리는 사용할 수 없습니다.

**끄기:** 터널 창에서 Ctrl+C → 서버 창에서 Ctrl+C 순으로 종료합니다. DB 파일을 삭제할 필요가 없습니다. 다시 켜면 같은 기록을 이어갑니다.

기본 규칙은 반복 참여입니다. 물주기와 미션 보상을 하루 한 번씩 제한하려면 첫 번째 창에서 서버 실행 전에 `$env:DAILY_LIMIT='true'`를 설정합니다. 제한을 해제하려면 `$env:DAILY_LIMIT='false'`로 바꾸고 서버를 다시 실행합니다.

## 8. 매주 4지선다 퀴즈 등록

관리 명령은 서버를 켜 둔 상태에서도 **별도 PowerShell 창**에서 실행할 수 있습니다. 같은 Windows 사용자로 실행하면 저장된 DB 폴더를 읽습니다.

```powershell
Set-Location 'C:\GrowGame\crops-grow'
New-Item -ItemType Directory -Force 'backend\content' | Out-Null
Copy-Item 'backend\quiz.template.json' 'backend\content\quiz-2026-11-09.json'
notepad 'backend\content\quiz-2026-11-09.json'
```

예시 JSON:

```json
{
  "week": "2026-11-09",
  "questions": [
    {
      "question": "이번 물주기는 성장률을 얼마나 올릴까요?",
      "choices": ["10%", "20%", "30%", "50%"],
      "correctIndex": 3,
      "explanation": "물주기 한 번에 성장률이 50% 올라갑니다."
    }
  ]
}
```

`week`는 **해당 주 월요일 날짜**로 바꿉니다. 위 날짜는 예시입니다. 문제는 최대 20개, 보기는 서로 다른 내용 정확히 4개입니다. `correctIndex`는 첫 번째 보기 0, 두 번째 1, 세 번째 2, 네 번째 3입니다. JSON은 UTF-8로 저장합니다.

```powershell
node backend/manage.cjs import-quiz backend/content/quiz-2026-11-09.json
```

저장 완료 후 학생이 미션 팝업을 다시 열거나 새로고침·재입장해 확인합니다. **문제 변경만으로 프론트를 다시 배포할 필요는 없습니다.** 같은 주 콘텐츠를 다시 가져오면 해당 주 내용을 갱신합니다. 행사 중 정답·문제를 바꾸기 전에는 백업해 두세요.

특별 미션은 `backend/special.template.json`을 복사해 `week`, `title`, `description`을 수정하고 다음처럼 가져옵니다.

```powershell
node backend/manage.cjs import-special backend/content/special.json
```

## 9. 백업·저장소 변경·복원

프로젝트 폴더에서 다음을 실행합니다. 서버가 실행 중이어도 일관된 DB 백업을 생성합니다.

```powershell
node backend/manage.cjs backup C:\GrowGameBackups\growgame-2026-11-11-1800.sqlite
```

파일명 날짜와 시간을 실제 값으로 바꿉니다. 같은 이름은 덮어쓰지 않습니다. 행사 전·후 백업을 권장합니다. 백업이 완료된 파일을 USB 등 별도 장소에 복사하면 노트북 고장에도 대비할 수 있습니다.

**기존 기록을 유지하며 DB 폴더를 바꾸거나 복원할 때:**

1. 현재 DB를 위 명령으로 백업합니다.
2. 터널과 서버를 종료하고, 다른 관리 명령도 종료합니다.
3. 새 빈 로컬 폴더를 만듭니다. 예: `D:\GrowGameData`.
4. 백업 파일을 새 폴더에 복사하고 이름을 **`growgame.sqlite`**로 바꿉니다. 기존 DB/WAL 파일과 섞지 않습니다.
5. 첫 번째 창에서 아래 명령으로 새 폴더를 선택합니다.

```powershell
$env:FRONTEND_ORIGINS='https://cropgrow.sangsangbar.com'
.\backend\start.ps1 -ChooseFolder
```

6. 터널을 다시 실행하고 학생 기록을 확인합니다. 확인 전까지 원래 폴더와 백업을 보존합니다.

빈 폴더를 선택하면 빈 DB로 시작합니다. `-ChooseFolder`는 기존 데이터를 자동 이동하는 명령이 아닙니다. 실행 중인 `growgame.sqlite`만 직접 복사하는 대신 `manage.cjs backup`을 사용하세요.

## 10. 자주 발생하는 문제

| 증상 | 확인할 내용 |
|---|---|
| `node`를 찾지 못함 | Node 24 설치 후 PowerShell 새로 열기 |
| `node:sqlite` 오류 | `node --version`이 24.13 이상 24 계열인지 확인 |
| `cloudflared`를 찾지 못함 | 두 번째 창에 `C:\GrowGameTools` PATH 설정을 실행했는지 확인 |
| 저장 폴더를 찾지 못함 | 외장 드라이브 연결·드라이브 문자 확인. 복원 절차에 따라 `-ChooseFolder`로 다시 지정 |
| 8787 포트를 이미 사용 중 | 이미 켜 둔 서버 창 확인. 서버를 중복 실행하지 않기 |
| 로컬 health도 실패 | 첫 번째 서버 창 오류부터 해결 |
| 로컬 health 성공, 외부 실패 | 두 번째 창의 터널 로그·토큰·학교망 7844 통신 확인 |
| 외부 health 성공, 앱에서 403 | 첫 번째 창의 `FRONTEND_ORIGINS`를 정확히 `https://cropgrow.sangsangbar.com`으로 지정하고 서버 재시작 |
| 다른 Windows 계정에서 토큰 복호화 실패 | 해당 계정에서 `start-tunnel.ps1 -ResetToken`으로 토큰 다시 입력 |
| 기록이 사라진 것처럼 보임 | 새 빈 DB 폴더를 선택했는지 확인. 원래 DB와 백업을 찾고 복원 |
| PIN을 잊어버림 | 서버 노트북에서 `node backend/manage.cjs reset-pin 1 1 24` 실행 후 새 PIN 입력. 예시는 1학년 1반 24번 |
| PIN 5회 오류로 잠김 | 15분 기다리거나 관리자가 위 명령으로 PIN 초기화 |

기억한 DB 경로는 다음 명령으로 확인합니다.

```powershell
Get-Content "$env:LOCALAPPDATA\growgame-server\config.json"
```

## 11. 코드 업데이트

Git으로 받은 경우 DB 백업 후 서버와 터널을 종료하고 프로젝트 폴더에서 `git pull --ff-only`를 실행합니다. 로컬 코드 변경이 있으면 먼저 확인하고 강제로 덮어쓰지 않습니다. ZIP으로 받은 경우 새 ZIP을 별도 코드 폴더에 풉니다. 학생 DB 폴더는 유지하고 다시 서버·터널을 실행합니다.

Cloudflare의 프론트는 GitHub `main`에 push하면 자동 배포됩니다. 노트북 코드는 자동으로 갱신되지 않습니다. 실제 운영 전 학교 노트북·Wi-Fi에서 예상 학생 수에 맞춰 접속 상태를 확인하세요.

개발 구조와 API는 [프로젝트 인수인계](PROJECT_HANDOFF.md), 세부 운영 명령은 [백엔드 안내](../backend/README.md)를 참고합니다.
