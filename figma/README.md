# Figma UI 편집본

[Figma에서 최신 입장 화면 열기](https://www.figma.com/design/YTnVeBMLrg8ZoybXgJ41TB/?node-id=9-955) · [최신 농장 화면](https://www.figma.com/design/YTnVeBMLrg8ZoybXgJ41TB/?node-id=9-1129)

2026년 11월 10일: 제목을 ‘마석중학교 농작물 키우기’로 반영하고, 시간·상태 표시를 숨겼습니다. 최신 12개 화면은 ‘게임 UI · 새 디자인’ 보드에 있으며, PC 브라우저 화면도 같은 모바일형 UI로 맞췄습니다. 이전 웹 형태 보드는 보관용으로 숨겨져 있습니다. 아래 제작 수량과 구성 기록은 최초 편집본 기준입니다.

위치: 미래교육부 → 작물 키우기 ui → 작물 키우기 UI 페이지.

## 화면 구성

- PC 3개: 나의 논밭, 우리 반 정원, 작물 도감.
- 모바일 5개: 나의 논밭 50%, 우리 반 정원, 작물 도감, 수확 준비 100%, 씨앗 0%.
- 모바일 팝업 4개: 미션 안내, 수확 완료, 다음 작물 선택, 참여 안내.
- 화면 모음 아래에 원본 이미지 41개를 교체·참고용 일반 레이어로 배치.

## 편집 방식과 검수

- 컴포넌트·컴포넌트 세트·인스턴스 0개.
- UI 화면 모음은 일반 프레임 234개, 텍스트 300개, 사각형 106개로 구성했습니다. 사각형 중 80개는 작물·바닥·캐릭터 이미지를 표시합니다.
- 글자는 직접 편집하고, 카드·버튼은 일반 자동 레이아웃 프레임에서 간격과 크기를 조정합니다.
- 성장 바는 배경과 채워진 영역을 별도 레이어로 나눴습니다.
- 기존 PNG 이미지 원본을 사용했습니다. 전체 UI를 스크린샷 한 장으로 합치지 않았습니다.
- 원본의 Malgun Gothic이 연결 환경에 없어 모든 텍스트를 Noto Sans KR로 통일했습니다.
- 구조 검사에서 컴포넌트 여부와 글꼴, 자동 높이를 확인하고 전체 화면 이미지를 검수했습니다.
- Figma에는 0%·50%·100% UI 상태를 정적인 편집 화면으로 재구성했습니다. 실제 성장 애니메이션은 기존 앱 데모에서 동작합니다.

## 로컬 파일

- `build-ui.js`: 편집용 UI 생성에 사용한 Figma Plugin API 코드.
- `upload.cjs`: 연결 도구가 제공한 일회용 업로드 계획으로 원본 PNG를 전송하는 도구. 업로드 URL은 파일에 보관하지 않습니다.
- `ui-review.png`: 최종 전체 구성 검수 이미지.
폐기된 브라우저 캡처 준비 파일은 정리했습니다. 현재 결과는 Figma 연결 도구로 직접 제작했으며, `build-ui.js`와 원본 업로드 도구는 디자인 작업 자료로 보존합니다.

생성 코드의 노드 ID는 이번 파일 작업에 연결되어 있습니다. 그대로 재실행하면 화면이 추가될 수 있으므로 기존 UI 수정은 Figma에서 직접 진행하세요.
